# 📈 Exploratory Data Analysis using Python (Jupyter Notebook)
 
The goal of this project is to **understand the data, explore patterns, and extract simple insights** through code, popular Python libraries and visualizations.


## What This Project Does -

- Loads data from CSV files
- Cleans and preprocesses the data
- Performs basic statistical analysis
- Explores trends and patterns
- Visualizes data for better understanding
- Derives simple insights from the dataset


## Libraries Used

- **NumPy** – numerical operations  
- **Pandas** – data loading, cleaning, and manipulation  
- **Matplotlib** – basic data visualization  
- **Seaborn** – for enhanced plots  


## Files in This Repository 

1. Black Friday sales Analysis
2. GDP analysis across countries
3. Heart Failure Prediction
4. playstore apps
5. Sugarcane Production across countries
